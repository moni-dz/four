# four (iv) - image viewer

supported formats:
- GIF
- JPEG (including arithmetic/progressive-arithmetic coding)
- JPEG XL
- JPEG XR
- PNG (including HDR PNGs with a PQ or HLG `cICP` chunk)
- TIFF

HDR tone mappers:
 - ACES
 - ITU-R BT2446-1 Method A
 - clamp
 - Hable's filmic (Uncharted 2)
 - Reinhard (luminance, extended, extended-luminance)
